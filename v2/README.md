# 卡啡 2.0 測試站

網址：https://zengkao.github.io/kafei-order/v2/

**這個資料夾是測試用的，正式站在上一層。** 由 `build_v2_testsite.py` 產生，
不要手改裡面的 html——下次重跑就沒了。改內容請改 `build_order_page.py`
的 HTML_TEMPLATE（訂購頁）或 `deploy/` 根目錄的對應頁面，再重跑：

    python build_order_page.py --json
    python build_v2_testsite.py

## 測試站與正式站的差別

| 項目 | 正式站 | 測試站 |
|---|---|---|
| 後端部署 | 釘在 50 版（1.0 程式碼） | 51 版起的 2.0 程式碼 |
| 商品來源 | 「商品庫存」分頁 | 「卡啡V2-庫存」分頁 |
| 商品快取鍵 | `products_json_v1` | `products_json_v2test` |
| 庫存版本鍵 | `STOCK_VERSION` | `STOCK_VERSION_V2TEST` |
| 訂單寫到 | 「訂單」分頁 | 「訂單_測試」分頁 |
| 下單後寄信 | 會寄 | 不寄，只寫執行記錄 |
| 開立發票 | 會開 | 不開，也不會作廢 |
| 搜尋引擎 | 收錄 | `noindex,nofollow`，且不在 sitemap 裡 |

隔離靠的是後端 `TEST_MODE` 常數（在 `gas_00_設定與選單.js`）。
**上正式站前必須把它改成 false。**

## 可以測什麼

幾乎全部：畫面、文案、分類篩選、加購物車、優惠金額計算、結帳表單驗證、
訂單確認彈窗的計算明細、真的送出訂單、庫存扣帳、超賣攔截、
賣貨便匯出、營業報表、VIP 擇優。

## 測不到什麼

發票開立與作廢（測試模式一律擋下，開真發票就是拿掉一個發票號）。
出貨通知信也不會真的寄出，只會寫進 Apps Script 的執行記錄。

## 前提

「卡啡V2-庫存」分頁要有商品，測試站才看得到真實資料。分頁是空的時候，
後端回空陣列，前端會沿用頁面內嵌的 12 款豆單當畫面，但下單會被判成售罄。
